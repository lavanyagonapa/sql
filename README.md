# Student Course Management System

## 📌 Project Overview

The **Student Course Management System** is a SQL-based database project designed to manage student details, departments, instructors, courses, and enrollments.

This project demonstrates how SQL can be used to store, retrieve, update, and manage relational database information efficiently.

## 🛠️ Technologies Used

- MySQL
- SQL

## 📂 Database Tables

The project consists of the following five tables:

1. **Departments** – Stores department details.
2. **Students** – Stores student information.
3. **Instructors** – Stores instructor details.
4. **Courses** – Stores course information.
5. **Enrollments** – Stores student enrollment details.
